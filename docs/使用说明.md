# ICT盲点表工具 · 使用说明

## 快速上手与完整例子

操作顺序：登录 → 导入报告 → 分类查看 → 确认原因 → 按需复制或导出。

以下是操作示例，位号、标准值及数量仅用于说明，不是所有报告的固定结果。

1. 在“分类筛选”点击“导入报告”，选择Coverage的xls或xlsx文件。导入后默认显示全部类型、全部检测项目和全部状态。

2. 假设报告中R103/NP、R104/NP的标准值都是10kΩ，缺件列均为Х；Q7_2_3/NP的缺件列为√。选择“缺件”，类型选“电阻”，状态选“Х 不可测”，可以看到前两个电阻。Q7不会进入缺件盲点表，NP和黄色底纹不改变√的结果。

3. 如果两个电阻的原因待确定，进入“待确认项”，勾选这两条缺件记录，在下拉框选择“无测试点，故不可测”，点击“批量确认原因”，核对数量和检测项目后确认。只有实际确认了无测试点才选择该原因，不根据这个示例推断其他元件。

4. 若下拉框没有合适原因，先到“盲点设置”新增原因，再返回选择。需要以后自动匹配时，在“规则设置”另建匹配条件；仅新增原因名称不会自动给所有元件归因。

5. 进入“复制整理”，选择对应10kΩ分组，展开复制工具。复制本组位号得到“R103.R104.”；复制本组四列后，在Excel盲点表的B列单元格粘贴，B—E分别为位号、数量2、标准值10kΩ和原因。不同类型、标准值或原因会分组。

6. 点击“导出盲点表”，选择保存位置。软件输出整份报告中缺件为Х的记录，不限于刚才查看的两个电阻。每次只生成一个xlsx，不附带核对报告。未知原因保留“待确定”。

## 登录

每次启动先显示登录页，用户名默认填入陈俊杰，密码留空。输入约定密码后点击登录或按Enter。密码默认遮蔽，可勾选显示密码检查输入。用户名或密码错误时会在登录框内提示。

关闭登录窗口即退出软件。软件采用离线登录，不提供注册、记住密码或自动登录；重启后需要再次输入密码。入场动画约0.8秒，结束后静止，不影响主界面操作。

## 分类筛选

用途：查看Coverage全部元件及四项检测结果。

导入报告后，左侧选择全部、缺件、短路、错件或空焊；上方选择元件类型、状态，并输入位号、标准值或原因关键词。多个条件同时生效，“清空筛选”恢复当前检测项目下的全部元件。

点击“全部元件、不可测、可测、不适用、原因待选择”卡片可切换状态范围。全部检测项目时每条源记录只显示一行；任一项Х归入不可测，适用项目全部√归入可测，提供的项目全部∕归入不适用。各检测列仍显示原始结果。

类型中的“待确认”用于查找原因、分类或数据问题。长原因可悬停查看完整文字，双击原因区域进入待确认项。

左侧统计是当前检测项目的整板统计；“全部检测项目”时显示缺件统计，不随类型筛选缩小。覆盖率按√数量除以总数计算，检测按钮显示四舍五入整数，左侧显示两位小数。值针率在“输出设置”中手动填写。

## 复制整理

用途：把相同类型、标准值及原因的Х记录整理为分组，手工粘贴到Excel。

沿用当前类型、位号、标准值及原因筛选，但复制内容只取Х。左侧选择“全部检测项目”时按缺件整理；切换具体项目可整理该项Х。

选中一组，点击“展开复制工具与本组位号”。“复制本组位号”用于粘贴元件位置单元格；“复制本组四列”从B列开始填入B—E列。位号按英文句点分隔，末尾有句点，换行不增加数量。

Excel正常粘贴可保留位号在一个单元格内；不要使用“仅粘贴纯文本”拆开换行。存在重复位号等数据问题的分组，复制按钮禁用，应先处理数据问题。

## 待确认项

用途：处理原因未匹配、规则矛盾及文件数据问题。

先检查每行检测项目和问题说明，再勾选需要修改的Х记录，选择原因并点击“批量确认原因”。“全选当前筛选”只选择当前结果内允许批量处理的记录；提交前会显示条数及项目范围。

批量确认只修改原因，不改变检测符号、原始位号或标准值。不同检测项目分别保存。未知符号、重复位号等文件问题不能通过批量选择原因消除，可选择“单条校准”检查。

“单条校准”可处理具体元件，并可把已确认的归因保存为规则。请检查预填的位号、标准值及项目范围，避免把个别元件情况误设成通用规则。

菜单右侧橙色数字是当前范围的待确认记录数，同一元件在不同检测项目存在问题时会分别计数。

## 盲点设置

用途：维护可选择的盲点原因名称。

搜索原因后，可以新增、修改、删除或恢复。填写修改人和说明后保存，原因下拉列表及关联显示会同步更新，修改记录保留。

例：新增“外部条件不足，故不可测”后，可在待确认项中选择这个原因。只有经过工程确认才应使用；新增原因名称不会自动生成匹配规则。

## 分类设置

用途：维护电阻、电容、二极管等元件分类及基础前缀。

新增或编辑分类时填写名称与前缀，如“保护器件”和一个尚未被占用的前缀。前缀填写英文字母，可用逗号、顿号或空格分隔；已有前缀冲突时会提示。

保存后筛选列表同步更新并重新分类。分类改名同步关联规则与人工结果；项目专属映射继续保留。删除支持恢复，对应元件可能进入待确认，不会改变原始检测符号。

## 规则设置

用途：把已经确认的原因判断保存为可重复使用的规则。

常用条件包括元件类型、前缀或指定位号、后缀、标准值及盲点原因。项目范围和优先级位于默认折叠的高级设置。填写修改人和说明，保存后重新匹配当前报告。

例：某项目已验证R103的不可测原因为无测试点，可限定项目、位号及必要条件建立规则；不要把项目特例扩大到所有电阻。

新规则默认适用于四项检测，旧规则编辑保留原适用范围和隐藏条件。规则冲突继续进入待确认；支持删除恢复，来源历史保留。不查看测试程序，不计算10%或30%的可测公式。

## 规则总览

用途：只读查看规则编号、阶段、优先级及当前执行内容。

可用来核对软件如何匹配原因；需要修改时进入“规则设置”。总览以“样品训练”概括来源，具体来源与历史仍保存在配置和项目文档中。

## 修改记录

用途：查看人工实际修改过的元件最终结果。

列表显示元件位号、类型、检测项目、标准值和盲点原因。自动分类和未修改元件不显示；同一报告、检测项目、源记录多次修改只保留最终结果，最新修改在前。

重新导入同一报告时，如提示恢复最终人工原因记录，选择恢复即可继续使用已保存的结果。规则设置操作另有自身历史，不混入此列表。

## 使用说明

用途：无需联网查阅软件操作方法。

从上方目录选择菜单名称即可跳转对应说明。第一次使用建议先阅读“快速上手与完整例子”，再查阅当前菜单。正文可滚动阅读及选中文字复制。

## 导出与常见问题

导出盲点表：始终输出整板ICT缺件Х，不受浏览的类型、状态或检测项目影响。没有缺件列或没有缺件Х时不生成空表。标题、明细和页脚沿用内置模板；未知原因写“待确定”，真实数据问题会提示待审核。

符号判断：Х/X/×纳入，√排除，∕不适用并排除。NP、黄色底纹及元件类型不改写检测结果；未知符号单独提示。

数量不一致：先核对是否查看了“全部检测项目”、是否存在类型或关键词筛选。上方卡片是当前元件范围，左侧是整板统计，导出是整板缺件Х；这三者可能不同。

无法导出或文件占用：关闭正在打开的目标盲点表，或选择新的文件名保存。不要覆盖原始Coverage文件。

小窗口：左侧菜单可上下滚动以找到“使用说明”，检测按钮、统计和底部署名保持可见。导入大表时等待状态栏完成读取后再筛选。
