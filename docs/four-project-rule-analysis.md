## 规则接入

原105条保留不变；追加11条BASE5共性规则和210条LEARN-5项目规则，项目规则分布17/19/99/75。共性条件包括电阻/电容/电感NP、R/C的PCB、电容C和SG，以及D/Q、IC、连接器、晶振、TVS。复合后缀保持排除条件和显式覆盖关系，不推导10%/30%公式。

规则通过已确认的类型和后缀匹配，而非单凭相同标准值猜测电路。具体31.6Ω并联4颗、100uF并联470uF、特定pF原因、显示标准值等限定完整项目号及位号/原值。项目规则明确覆盖相关基础条件；老项目保留原有分类边界。

类型补充采用精确前缀；同一前缀在不同位置含义不同的情况，使用项目＋位号＋原值约束，不能把所有L/LD/F全局改类。源值20pF的L3及0.750V的LD1—LD3等一致证据只作对应项目类型补充。

根据用户选择，新规则适用四项，旧规则的原检测范围保留。四组人工原因真值来自缺件表；其他检测项目的符号逐列读取，原因仍可在软件中人工校准，不声称四项物理原因都经过独立人工验证。
