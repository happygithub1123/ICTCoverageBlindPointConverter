# v0.4.1 · 分类独立分组与盲点设置

设计人员：王开心 · WANG KAIXIN · WHAPPY

## 分类与导出

修复标准值和原因相同时不同类别被合并的问题。预览、两个复制按钮和Excel导出共用“元件类别＋标准值＋原因”分组；同一分组按源记录顺序列出位号，各组单独占一行和一个位号单元格。

- D、Z、ZD为普通二极管类别，可以按相同标准值和原因合并。
- TVS为独立分组，即使用户将其元件类型设为二极管，也不与普通二极管混在一个单元格。
- M按IC识别，独立于二极管和TVS。电阻、电容、电感、三极管等同样不会跨类别合并。
- 未识别的前缀各自分开，避免多个未知类别混成一组。

原因没有匹配或存在冲突时，输出“待确定”，可以直接复制或正常导出盲点表，不会仅因原因未知而要求待审核版本。未知检测符号、重复位号等数据问题继续单独提示；检测结果始终以Coverage为准。

## 盲点设置

左侧新增“盲点设置”。“盲点原因”页提供搜索、新增、修改名称、删除、恢复；“操作记录”页显示保存的操作、名称变化、修改人、时间和说明。

原因编号保持稳定。改名后同步到规则、当前报告以及原因选择列表。删除后从可选原因中隐藏，关联规则和历史引用保留，对应未明确原因显示“待确定”；勾选“显示已删除”后可恢复。原样保存不增加重复操作记录，同名原因不重复创建。

从原因选择表单或规则编辑器新增原因，也会记录到此目录。操作记录保存在用户配置中，不混入人工元件修改日志，也不会作为导出附件。
