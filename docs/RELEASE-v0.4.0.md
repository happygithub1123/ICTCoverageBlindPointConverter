# v0.4.0 · 四项检测筛选与三组项目规则

设计人员：王开心 · WANG KAIXIN · WHAPPY

## 使用变化

- 自动识别ICT缺件、短路、错件、空焊列。四张彩色卡片展示覆盖率与√/Х/∕数量，点击即可切换检测项目或状态。
- 类型、位号、标准值决定卡片统计范围；状态和原因筛选不改变统计分母。左侧保留当前检测项目的整板数量、不可测数和覆盖率。
- 值针率继续人工输入。项目只自动识别；无匹配项目时使用基础规则。
- 原因可以手动选择或新增并保存为规则，缺件/短路/错件/空焊分别维护，旧规则按缺件兼容。
- 人工修改日志只显示最终的位号、类型、检测项目、标准值、原因，同一元件同一检测项目仅保留最后结果；自动分类、原样保存和规则管理不加入此列表。
- 导出当前检测项目、当前筛选内的Х记录，仍仅生成一个盲点表.xlsx。内置通用模板、两个复制按钮、署名和图标保留。

## 三组规则学习

新增71条项目限定的缺件原因规则，保留原34条规则及历史。三组逐点核对后分别输出275/286/250个盲点，24/26/20组，原因待确认均为0。

第二组人工表中相同标准值和原因的两行合并，不减少位号。第三组修正人工表漏列的C101，总数按Coverage保持250。详见 [三组差异分析](three-project-rule-analysis.md)。未将这些项目的特例应用到其他板卡或其他检测项目，也不新增10%/30%公式或程序证据要求。

## 验证与兼容

112项本机回归全部通过，涵盖四项整板统计、电阻筛选、移动列/缺列、状态筛选分母、按项目隔离、旧规则和旧会话、最终日志、剪贴板、模板及单文件导出。整板样例为202/1000、381/821、202/1000、202/1000，卡片17%/32%/17%/17%；电阻550个，缺件88/462、短路67/483。缺件完整样例仍为1000个位号、99组，Q7排除。

配置首次从rules-v3.json或rules-v2.json迁移至rules-v4.json，旧文件保留；自定义规则和已归档规则保留。新会话按报告指纹、检测项目和源行恢复最终原因；旧会话按缺件兼容。保留v0.3.2文件共享读取修复。

解压整个Windows x64运行包，双击ICT盲点表工具.exe。原有版本和GitHub Release保留。
