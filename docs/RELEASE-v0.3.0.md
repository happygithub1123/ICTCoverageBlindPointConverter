# v0.3.0 · WHAPPY 简洁版

设计人员：王开心 · WANG KAIXIN。Designed by WHAPPY。

## 使用方式

导入 Coverage 报告 → 按元件类型查看分组 → 复制或导出盲点表。

- 仅整理ICT缺件列的X/Х/×/✕。√可测、∕无此不良现象，直接排除。黄色底纹和NP不覆盖检测符号。
- 不再要求重复确认可测性或提供测试程序。自动匹配原因，未匹配或相互矛盾的原因才需要选择；格式未知、位号重复等真实数据问题仍会提示。
- 示例直接得到1202条记录、1000个盲点、202个可测、99组，原因待选择为0。Q7_2_3/NP的缺件列为√，不纳入盲点，也不再提示冲突。
- 内置示例通用模板，取消模板选择。每次导出只生成一个盲点表.xlsx，不再生成核对报告或日志附件。
- 复制仅保留“复制本组位号”和“复制本组四列”。
- 浅色内容区、深色导航、黄色品牌点缀、蓝色操作和绿色导出；增加提供的图片图标及WHAPPY署名。
- 规则设置改为表单新增、编辑、删除及恢复；规则总览和人工修改日志留在软件中。

## 规则与保存

规则版本2.1.0，schemaVersion保持2。新程序使用rules-v3.json，首次迁移已有rules-v2.json（原文件保留）；旧审核会话不自动套用到当前简化流程。

源检测状态只读；人工原因选择仅适用于X记录。10%/30%仍不进行公式推算，SG没有有效原因时可直接由用户选择盲点原因；不要求测值或程序证据。旧规则元数据及来源作为历史依据保留。

内置通用模板不依赖运行目录中的samples，运行包不再附带测试样例。代码仓库仍保留样例用于回归。

删除规则采用停用归档，可以恢复；记录修改人、理由和前后内容。核心管线规则只读，避免删除读取或统计功能。规则更改后自动重新分析，旧人工选择记录保存于本地历史会话。

## 验证

48项自动测试覆盖符号筛选、原因选择、固定模板单文件导出、99组与1000位号、模板页脚、剪贴板、规则新增删除恢复、持久化和界面表单。已视觉检查正常窗口和1120×760小窗口。程序使用DPI自动缩放；尚未在不同系统实际DPI设置下逐一验收。

WPS/Excel实际粘贴的人工视觉验收尚未完成；已测试剪贴板结构、换行以及四列内容。
