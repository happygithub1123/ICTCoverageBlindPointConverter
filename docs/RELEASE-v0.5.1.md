# v0.5.1 · 导入与界面性能优化

修复导入后主线程集中刷新表格造成的停顿。v0.5.0虽然已后台读取文件，但返回界面后仍同时填充主表、隐藏的复制/异常页及人工日志，并逐行设置高度、提示和选择状态；记录增多会放大这段阻塞。

## 优化内容

- 主表和异常页使用虚拟列表，只读取可见单元格；统一行高、悬停提示按需获取，滚动采用双缓冲。
- 隐藏页面打开时再刷新。导入只刷新主表一次，不重复重建全部页面；页面切换保留未变化的勾选结果。
- 位号、标准值、原因搜索停顿180毫秒后统一执行，切换页面时立即应用最后输入。
- 人工记录恢复、批量与单条保存、规则重算及关闭时保存均在后台执行。批量保存成功后才替换当前数据，失败保留原结果。
- Excel显示值格式化器按线程复用，原因规则按检测项目、项目范围和类型预先筛选，保留原规则优先级与匹配条件。
- 导入状态栏显示读取文件、识别检测列、匹配原因、恢复记录等阶段。

## 本机实测

同一1202条样例，Windows x64 / .NET 8；隐藏窗口保留真实WinForms消息循环，20毫秒定时器检测响应间隔。以下为本机单次记录，其他电脑和文件耗时可能不同。[原始指标](performance-v0.5.1.json)。

| 检查项 | v0.5.0 | v0.5.1 |
|---|---:|---:|
| 导入至主表就绪 | 2117毫秒 | 1194毫秒 |
| 导入期间最长消息响应间隔 | 758毫秒 | 196毫秒 |
| 刷新主表及关联统计 | 1093毫秒 | 21毫秒 |

额外使用10000条内存记录：主表刷新105毫秒、异常页首次打开195毫秒；验证末行显示、全选、单条取消、禁止选择未知符号、页面切换保留勾选及搜索延迟生效。响应回归上限为1500毫秒，以捕获重新引入逐行UI操作的退化。
