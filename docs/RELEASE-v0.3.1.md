# v0.3.1 · 直接按报告结果整理盲点

设计人员：王开心 · WANG KAIXIN。Designed by WHAPPY。

## 本次优化

- 所有元件统一依据ICT缺件列：X/Х/×/✕纳入，√/✓/✔和∕排除；D、Q、IC不例外。
- 黄色底纹、NP和元件前缀不改变检测结果，不读取测试程序，不计算10%或30%。
- 移除旧程序字段与规则状态组合形成的校验限制。旧自定义规则及会话字段兼容保留，不参与可测性或原因校验。
- 规则总览分为“当前执行”和“历史依据 / 历史来源”；历史需复核说明不作为用户当前操作要求。
- 默认配置中的旧程序标记和原动作、状态保存在historicalEvidence；旧待确认定义保存在historicalPendingDefinitions，均明确为历史记录。原因文案、实际匹配条件和优先级不变。
- 继续使用WHAPPY简洁界面、图标、署名及内置模板。只保留两个主要复制按钮。
- 每次仅导出一个盲点表.xlsx，不额外生成核对报告或日志文件。

## 兼容性

默认运行规则为2.1.1，schemaVersion仍为2。使用同一个rules-v3.json路径，不覆盖已有用户规则；用户自定义条件、启用状态、编号、来源、版本和未知JSON扩展字段继续保留。旧RequiresProgram、ReviewOutsideSample、ProgramEvidence字段可读取及保存，但不参与当前流程。

项目特例依然仅在对应项目启用。原因未匹配或矛盾时选择原因；未知符号、重复位号等真实数据问题继续单独提示。

## 回归验证

示例保持1202条、1000个盲点、202个可测、99组、0条重复可测性确认；Q7缺件列√直接排除。保留C246、RA4、P21001。

新增48种D/Q/IC符号、底纹和NP组合，并验证旧程序字段不能触发限制；另外覆盖旧配置往返保存、自定义规则、删除恢复、规则总览说明和D/Q/IC单文件导出。保留现有界面、复制、原因选择、模板和页脚回归。

Windows x64自包含发布，旧版本保留。WPS/Excel实际粘贴及不同系统DPI的完整人工验收仍属于未完成的环境验证；本版本没有扩大这些验证结论。
