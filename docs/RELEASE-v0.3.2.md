# v0.3.2 · 修复报告被Excel/WPS占用时的读取错误

## 修复内容

- 读取Coverage时允许其他程序保持读写打开；只读取文件已保存的内容，不修改源文件。
- 一次导入先获取只读内存副本，表头识别、解析和会话指纹全部使用同一份内容，防止两个阶段读取不同版本。
- 会话保存和恢复使用导入时记录的指纹，不再反复打开原文件。因此导入后文件被重新保存或占用，也不影响本次数据的原因选择记录。
- 读取过程中检测到文件大小或修改时间变化时短暂重读；仍不稳定则中文提示等待保存完成。
- 真正的独占锁不能绕过，提示“保存并关闭Excel/WPS中的该报告后重试”，不再只显示英文系统异常。

符号筛选、原因分类和模板不变，每次仍只生成一个盲点表.xlsx。Excel/WPS内未保存的修改不会自动读取，保存后点击“读取分析”更新。

## 验证

新增共享读写占用、允许只读共享的编辑器占用、完全独占锁、解析期间文件被替换和界面会话指纹回归。保留样例1202/1000/202/99、符号筛选和单文件导出等测试。

共享占用场景由Windows文件句柄模拟；未声称在所有Excel/WPS版本中逐一完成实机验证。
