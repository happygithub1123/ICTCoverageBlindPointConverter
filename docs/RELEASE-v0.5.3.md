# v0.5.3 · 大表性能与类型分类设置

本版针对MG10P0B3270335大表导入、滚动与高CPU问题重写主表绘制，并减少人工记录恢复和批量修改的重复计算。检测规则、四项筛选、批量确认及单文件导出保持不变。

## 性能

- 主表使用轻量只读视口，绘制量由可见行决定，不为整板创建单元格对象。行图像缓存最多64项，并按16MB预算限制；字体、尺寸、数据变化时清空缓存。
- 滚轮输入按16毫秒合并，切换页面、失焦、筛选和边界停止积压输入；保留键盘移动、点击选中、完整原因提示。
- 报告复制改用明确的数据复制，避免整板JSON序列化往返；人工记录通过源行索引恢复，重复位号检查统一执行一次。
- 新会话只保存最终人工修改，避免每次保存四份完整报告和中间编辑JSON；规则校验、项目覆盖及类型匹配复用索引。
- 缓存行使用不透明位图和清晰文字绘制，修正文字黑边。隐藏页面仍按需刷新。

## 界面、导出与分类

- 恢复v0.3.2式左侧品牌图标及设计人员署名，署名字体加大，保留v0.5主表优先布局。小窗口可滚动左侧菜单，四项检测按钮及统计保持可见。
- 按钮为“导出盲点表”。输出恢复原模板标题与统计区域，不写“检测项目”“筛选范围”“筛选总数”；仍按整板缺件Х生成一个xlsx，浏览筛选不影响导出范围。
- 新增“类型分类设置”：分类搜索、新增、编辑、删除恢复、基础前缀维护及修改记录。改名同步关联规则和人工结果，删除不抹去历史；前缀冲突会提示。
- 配置迁移到rules-v6.json，首次兼容V5/V4/V3/V2；新会话位于sessions-v6，旧配置和会话保留，支持旧版本继续使用。

## 验证

133项回归，132通过，1项因旧三组原始文件缺失跳过。四组新实表继续逐点核对54/358/1144/1022个缺件盲点；原样例1202条、1000个盲点、99组。检查分类增删改恢复、旧会话、批量原子保存、复制、导出回读和模板标题。

MG0335独立实测：1740条记录导入约816毫秒；180次滚动、选中及完整视口绘制，95%帧约16.1毫秒，最长25.8毫秒；活动约5.03秒，UI线程CPU时间2.00秒；随后500毫秒空闲阶段UI线程CPU增量为0。[原始计时](performance-v0.5.3.json)。旧版相同MG测试超过120秒未结束，未取得可靠CPU对照，不报告降低百分比。这些是本机程序内测试，不代表所有设备的实际桌面帧率。

检查1120×760和1440×960程序内渲染截图。桌面捕获工具超时，因此本次使用应用消息循环、连续绘制测试和程序内截图验证；另对发布版执行启动响应检查。

Windows x64自包含发布；保留旧版本。用户原始四组报告不新增公开分发，326条已有规则及来源继续保留。
