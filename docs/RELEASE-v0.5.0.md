# v0.5.0 · 主表优先、批量确认、规则简化

设计人员：王开心 WANG KAIXIN · WHAPPY。顶部醒目署名，并显示“本软件最终解释权归王开心”。

## 主界面

分类筛选、复制拆成独立菜单。左侧大字体导航及全部/缺件/短路/错件/空焊固定选择区；每次导入默认全部类型、全部项目、全部状态。主表一条源记录一行，完整保留四项符号、元件类型、位置、标准值和原因；类型增加待确认。复制位号与工具默认折叠，不占主表。

全部视图按源行统计，Х为任一项不可测，√为适用项全可测，∕为提供的项目均不适用，未知符号独立提示。整板导出始终采用缺件Х，左侧全部模式明确标注缺件导出口径。

## 批量原因与规则

异常页支持勾选、全选当前筛选、原因选择和批量确认。先校验所有记录，只改所选Х的原因；文件问题不可批量绕过。以临时数据准备，文件原子保存成功后更新界面，失败不保留部分修改。人工日志只显示最终结果。

规则列表恢复v0.3.2风格，删除检测项目列和表单选项；常用五项参数可直接填写，编号、来源、修改人自动生成，低频条件默认折叠。新规则适用四项，旧规则原范围及隐藏条件不变。原因维护、删除恢复和来源历史保留。

## 四组学习及导出

规则2.3.0共326条：保留105条，新增11条共性、210条项目规则。四组缺件Х为54/358/1144/1022，0335/0336分别15/1个矛盾位号输出待确定。详见[four-project-rule-analysis.md](four-project-rule-analysis.md)。

“导出整板盲点表（缺件）”不受浏览筛选影响，固定模板，每次只有一个xlsx；缺少缺件列或没有Х时不产生空表。保留共享读取和人工值针率，不推算10%/30%或查看测试程序。
