# v0.5.2 · 连续滚动与界面整理

针对分类筛选里的快速滚轮、滚动条拖动和点击停顿，补充连续操作检查。v0.5.1主要优化导入后的数据刷新，未充分验证密集滚动消息；本版增加输入合并、视图缓存及实际视口绘制测试。

## 滚动与点击

- 16毫秒合并快速滚轮输入，单帧限制处理量，避免一次积压占满消息循环；到达边界、失焦或切换筛选时停止旧输入。
- 同步合并滚动条拖动，捕获完整32位位置，停止拖动时落实最后位置；保留滚动处理器对位置的校正，不通过回放过时消息读取错误位置。
- 缓存全部/缺件/短路/错件/空焊的展示字段、综合状态和原因；筛选复用结果。报告或规则变更、人工修改后自动失效，避免显示旧原因。
- 字体样式设在检测列上，减少逐格重复设置；悬停原因按需提示，滚动时隐藏提示；页面切换合并布局，保留虚拟列表与双缓冲。
- 保持连续滚动、四项原始检测结果和筛选语义，不增加分页。固定模板导出、原因校准和最终人工日志继续使用原数据。

滚动条实现核对了[.NET 8 ScrollBar源码](https://raw.githubusercontent.com/dotnet/winforms/v8.0.8/src/System.Windows.Forms/src/System/Windows/Forms/ScrollBar.cs)及[Microsoft GetScrollInfo文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getscrollinfo)。配置中的326条规则和来源未更改。

## 界面

- 主按钮简写为“导出盲点表”，输出仍为整板缺件Х，不受浏览筛选影响，每次只有一个xlsx。
- “V2规则总览”改名为“规则总览”。删除总览的项目、历史依据和具体来源列，上方仅写“样品训练”；完整来源、项目范围及历史仍保存在配置和文档中。
- 顶部图片所在行改为限定高度，完整缩放显示图片；扩大图片与署名间隔、左侧菜单宽度和按钮间距。保留大字体署名、全部检测项和彩色统计。

## 验证

126项回归：125通过，1项因旧三组源文件缺失跳过。四组新文件在本机逐点回归，缺件盲点仍为54/358/1144/1022；原样例仍1202条、1000个缺件盲点、99组。

同机使用相同异步测试脚本复测旧版：1202条样例的600次密集滚轮输入同步处理约499毫秒，本版约1.7毫秒，随后按16毫秒节奏继续滚动；该指标不等于600次滚动已全部绘制完成。本版130次滚动、选中与完整视口绘制，包含221/704/1740/1415条的四组实表，单次最长约49毫秒，最长消息响应间隔约300毫秒。万行主表和异常页检查继续通过。[实测记录](performance-v0.5.2.json)。耗时受机器与系统调度影响，不作所有设备的流畅性保证。

补充32位拖动位置、600次合并为一次通知、滚动处理器位置修正、取消旧输入、修改原因和规则后的缓存失效检查；检查1120×760和1440×960渲染结果、完整图标及规则总览。测试等待改用异步完成，避免同步线程等待干扰计时。电脑实窗截图捕获报“window capture timed out”，本次视觉检查使用程序内渲染截图，交互验证使用消息循环及滚动绘制测试。

Windows x64自包含发布，继续使用rules-v5.json及原人工会话格式，旧版本保留；用户原始四组文件不新增公开分发。
