# v0.5.5 · 登录规则与柔和循环动画

登录时用户名、密码均为空，允许君和辰、陈俊杰、WHAPPY、星联达四个用户名，WHAPPY须大写。用户名忽略首尾空格；密码必须恰好六个0—9数字，数字之和为20，允许开头为0，例如234542、000299。旧密码失效，不保存账号或密码。

## 登录页

- 首次约0.8秒完成Logo缩放淡入、英文标题轻微上浮、中文标题延迟渐显及卡片轻微滑入，随后约6秒一轮柔和呼吸与文字颜色渐变。
- 右上角显示“江苏君和辰科技有限公司”，采用蓝绿及少量金色分段文字和柔和亮度变化。
- 循环时卡片、输入框及按钮位置固定；焦点边框平滑变蓝，按钮有悬停和点击反馈。成功后提示“登录成功，正在进入…”约0.3秒再进入软件。
- 一个33毫秒计时器驱动所有动画，背景沿用尺寸缓存，只刷新相关区域，字体按尺寸缓存。最小化暂停，恢复继续，关闭后释放资源。

壁纸、完整中英文标题、菜单、主表性能、检测规则及单文件导出范围保留。使用说明和README同步新登录规则。

## 验证

146项回归：143通过，3项因本机原始文件缺失跳过（旧三组、四组实表及MG0335实表性能）。历史MG0335计时未作为本次重跑；现有样例与万行性能测试通过。覆盖四个账号、大小写、空输入、六位数字求和、前导零、长度错误、空格、全角数字、字母及旧密码失效；覆盖密码遮蔽、Enter提交、成功等待和重新启动。

登录页检查900×600、1200×760、1500×950和1800×1140，核对公司名称、标题与卡片范围。连续跨过一个完整循环，验证输入内容、光标位置、卡片位置不变化，背景缓存不重建，最小化暂停和关闭停止。主界面缩放、复制、人工修改、规则和导出回归继续通过。

持续动画测试同时执行70次完整窗口渲染：约9.58秒内进程CPU时间2.05秒、私有内存增量约2MB、背景重建次数0。该计时包含完整窗口测试绘制，并非实际桌面小区域动画的单独CPU数据；本机数据不代表所有设备。布局检查采用程序内渲染与缩放模拟。

构建使用已安装.NET 8及既有依赖；本次NuGet漏洞信息服务暂时不可达，产生NU1900提示，未更新依赖版本。Windows x64自包含发布，发布版启动检查后上传Public GitHub，旧版本保留。
