# 登录优化本地试用版 · 2026-11-09

仅本地交付，不发布新版本、不覆盖GitHub附件。v0.5.5下载页已转草稿并保留两个附件，v0.5.4恢复公开最新版；已推送源码未回滚。本次修改仍留在本地工作区。

## 界面

完整中英文标题固定位置，以约6秒周期呈现蓝绿流光，中文稍微错开。Logo和公司名称保留柔和效果。登录卡片叠加50%透明浅色底，输入框、文字和按钮清晰显示；取消用户名、密码标签与提示文字，两个输入框每次启动均为空，上框输入用户名、下框输入密码。保留显示密码、Tab、Enter及输入错误提示。

四个用户名与六位ASCII数字之和等于20的离线校验保持不变。菜单、检测规则、主表和导出范围未修改。

## 实现

标题、公司名称及Logo分开局部刷新，一个42毫秒计时器按实际时间推进。字形路径和公司名称尺寸在布局时生成，同时将字形预渲染为抗锯齿遮罩；每帧只按列移动亮色强度并更新复用的像素缓冲，避免反复测量和填充复杂路径。Logo按显示大小预缩放，半透明卡片也预合成底图。壁纸仅在尺寸改变时重建。最小化或隐藏暂停，恢复继续；成功与关闭释放资源。

## 性能验证

两版均使用1200×760窗口、预热后60秒、相同输入及密码显隐操作。测试窗体放在屏幕外，以免在用户桌面显示测试账号；Windows会省略屏幕外WM_PAINT，因此测试将实际失效区域合并后在复用画布上调用绘制。以下是**程序内局部绘制基准，不是实际桌面帧率**，CPU数值是测试进程累计CPU时间，非任务管理器整机占用率。

## 回归与边界

149项测试：146通过、3跳过、0失败。覆盖登录规则、空白重启、错误输入、密码显隐、Tab、Enter、关闭退出、最小化/隐藏恢复、资源释放、流光像素变化及卡片50%混合值。布局渲染覆盖800×560、900×600、1200×760、1500×950和1800×1140；大尺寸用于缩放布局核对，并非声称切换了Windows系统DPI。程序内预览确认标题、公司名称和卡片完整；未进行真实显示器逐帧闪烁测量。

主界面样例1202条、1000盲点、99组以及万行性能、筛选、滚动、复制、原因确认、规则和单文件模板导出回归通过。缺失原始文件的旧三组、四组及MG0335实表性能测试跳过，历史结果不冒充本次实测。

构建使用现有.NET 8依赖缓存；NuGet漏洞信息服务无法连接时出现NU1900，不影响本次编译，未更新依赖。
