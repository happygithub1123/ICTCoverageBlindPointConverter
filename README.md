# ICT 盲点表工具 · V2 v0.2.0

[下载 Windows x64 运行包](https://github.com/happygithub1123/ICTCoverageBlindPointConverter/releases/latest) · [V2规则说明](docs/v2-integration.md)

本地 Windows 桌面程序，读取 Coverage Excel，按元件类型筛选不可测元件、分组复制，或按现有模板生成盲点表。

## 运行

Windows x64 发布目录包含 .NET 运行时，无须安装 .NET SDK 或 Microsoft Office。解压整个压缩包，在目录内双击 `ICT盲点表工具.exe`。请保留同目录的 DLL、config、samples 等文件，不要只复制 EXE。

`samples` 包含原始 Coverage 和盲点表模板。首次启动默认选择随包样例；处理自己的项目时重新选择报告和模板。

## 筛选并复制到手工盲点表

1. 选择 Coverage（xls/xlsx），点击“读取分析”。筛选与复制不需要输出模板。
2. 类型选择电阻、电容、电感、二极管等；可叠加标准值、原因和位号搜索。
3. 结果按“标准值＋原因”分组。点击分组，在下方查看完整位号及来源明细。
4. “复制本组位号”粘贴到一个元件位置单元格；“复制本组四列”从 Excel 的 B 列开始粘贴，填入位号、数量、标准值、原因。使用普通粘贴以保留表格剪贴板格式。
5. 位号格式为 `R103.R104.`，末尾保留英文句点。换行宽度可调整，不影响统计数量。
6. “复制筛选内全部位号”仅复制位号清单，用于整理核对；不同值和原因不会强行合并为一个分类。

Excel 兼容的 HTML 和 Unicode 文本剪贴板已实现，自动测试验证了分组四列和换行格式。当前环境中 WPS 窗口捕获超时，尚未完成 WPS/Excel 实际粘贴的人工视觉验收。

## 自动生成盲点表

1. 读取分析后选择 xlsx 模板，核对光板编号、成品编号，按需要填写值针率和默认备注。
2. 默认备注留空时沿用模板原备注；值针率由用户提供，程序不计算其来源。
3. 点击“生成盲点表”，另存到新文件。程序同时生成核对报告并回读校验输出位号和数量。
4. 有待确认项时先到“异常 / 待确认”页选择记录并人工修订，填写修改人和修改理由；也可明确选择生成带“待审核”标记的版本。
5. 标题、Logo、列宽、边框、备注和签字区来自模板。明细增减时移动底部区域，长位号清单按需要增加行高。

## V2规则与审核

运行规则版本2.0.0，含34条基线规则。来源、优先级和变更见 `docs/v2-integration.md`；发布说明见 `docs/RELEASE-v0.2.0.md`。

- 仅按ICT缺件列判断源状态，NP/黄色作为证据；未知状态进入审核。
- 样例源统计1202条、202可测、1000不可测，99组。Q7源标记√保持不变，另列人工审核。
- 默认72条待确认：D/Q/IC原因66条、/NP/R四条、C199混合标记一条、Q7一条。在“异常 / 待确认”选中记录并点击“修改选中异常”，填写修改人和理由；可补充测试程序证据。正式导出需处理完成。
- 人工改判只改变输出决定，保留原始标记与源统计，输出数量重新计算。核对报告分别列出源统计、输出统计和全部候选规则来源。
- 10%、30%参考参数不计算可测性；SG仅记录待审核证据；D/Q/IC没有程序依据时不能把历史建议原因当成已验证结论。
- “V2规则总览”展示规则编号、优先级、启用状态、可靠性和来源；“规则设置”可维护运行JSON。`docs/rules.catalog.v2.json`仍是历史文档台账，不能导入程序。
- 项目默认自动识别；“通用（关闭项目特例）”明确关闭特例。指定项目规则时由用户明确选择。
- 默认备注留空沿用模板，值针率留空显示“未提供”。

## 规则和人工修订保存位置

默认运行规则随包放在 `config/rules.json`，首次启动复制到 `%LOCALAPPDATA%\ICTCoverageBlindPointConverter\rules-v2.json`。后续程序读取用户目录版本，重新解压发布包不会覆盖已有自定义规则。规则页支持编辑、校验、导入、导出及加载默认到编辑器，点击“保存并应用”后重新读取报告。

人工修订按源文件内容、规则内容和项目配置保存到同一用户目录的会话 JSON。再次读取相同文件和规则时询问是否恢复。核对报告包含修改前后、理由和时间，V2同时记录修改人和规则版本。

## 源码构建和发布

开发需要 .NET 8 SDK；运行发布包不需要 SDK。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Version 0.2.0
```

脚本自动查找 PATH 或 `C:\Program Files\dotnet\dotnet.exe`。发布脚本先执行 Release 测试，再生成自包含目录、使用文档、文件校验清单及 ZIP。相同版本的发布目录已存在时停止，避免混入旧文件；重新发布请使用新的版本号。

无法保存输出时，关闭 Excel/WPS 中占用该文件的窗口并检查目录权限。未知字段、未知标记和损坏文件会显示错误或进入审核，不会静默作为已完成结果。
