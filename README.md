# ICT 盲点表工具 · WHAPPY v0.4.0

**设计人员：王开心 · WANG KAIXIN**
**Designed by WHAPPY**

[下载 Windows x64 运行包](https://github.com/happygithub1123/ICTCoverageBlindPointConverter/releases/latest) · [当前版本说明](docs/RELEASE-v0.4.0.md)

本地运行的 C# WinForms 软件，将已经确认的 Coverage 报告整理成 ICT 盲点表。

## 运行

解压整个运行包，双击 `ICT盲点表工具.exe`。支持 Windows x64，自带 .NET 运行环境，无须安装 Microsoft Office 或 .NET SDK。请保留同目录 DLL 和 config，不要只复制 EXE。

## 主要操作

1. 点击“导入报告”，选择 `.xls` 或 `.xlsx`，自动读取分析。也可拖入报告。
2. 在“分类筛选 / 复制”中选择电阻、电容、电感、二极管等，点击彩色卡片选择缺件、短路、错件、空焊，或点击√/Х/∕数量筛选状态。默认“缺件＋Х”。
3. “复制本组位号”用于一个单元格；“复制本组四列”从 Excel B 列起粘贴位号、数量、标准值、原因。位号为 `R103.R104.`，保留末尾英文句点和换行。
4. 未明确的原因在“异常 / 待确认”中选择，也可输入新原因并保存为规则。表单预填检测项目、位号、标准值和项目范围。无需重复确认可测性或提交测试程序。
5. 点击“导出盲点表”选择保存位置，导出当前检测项目、当前筛选范围内的Х。没有Х时不生成空文件。每次**只生成一个盲点表.xlsx**，不会附带核对报告或日志文件。

内置模板固定使用示例格式，自动保持标题、Logo、列宽、边框、备注及签字区。项目编号、统计和明细由当前报告覆盖。导出后可打开文件或所在目录。

“输出设置”默认折叠，可修改项目编号、值针率、备注和位号换行宽度。默认备注留空沿用模板，值针率不填写则显示“未提供”。

四张卡片显示“√数量÷元件总数”的覆盖率，四舍五入为整数，鼠标提示提供精确值。卡片随元件类型、位号、标准值筛选，不随状态和原因筛选改变分母。空范围显示“—”，报告缺少检测列则显示“未提供”。左侧始终显示当前检测项目的整板统计，不随类型筛选缩小。值针率保持人工输入，不自动计算。

## 检测规则

- **X/Х/×/✕：不可测，纳入盲点表。**
- **√/✓/✔：可测，排除。**
- **∕/／：无此不良现象，排除。**
- 黄色底纹和NP只作为原始信息，不改变以上结果。

软件只整理已经确认的检测结果并匹配盲点原因。10%、30%不自动生成判断公式，D/Q/IC不再要求测试程序证据；没有匹配原因时由用户选择。未知检测符号和重复位号等数据问题仍会提示，避免无声遗漏。

样例1202条，缺件1000个盲点、202个可测、99组；短路381可测/821不可测，错件和空焊均202/1000，卡片显示17%/32%/17%/17%。电阻550个，缺件88√/462Х，短路67√/483Х。Q7_2_3/NP的缺件列为√，直接排除。以上数字仅为样例回归预期，不是产品固定值。

## 规则管理

“规则设置”支持表单新增、编辑、删除和恢复分类规则，可设置适用检测项目、类型、前缀、后缀、原始标准值、显示标准值、指定位号或位号集合、原因、优先级、项目范围及来源。原因下拉框可输入新原因。数值小的优先级先匹配；不同原因发生未定义冲突时进入原因选择。“覆盖规则编号”可明确声明覆盖关系。旧规则默认只属于缺件，不自动用作短路、错件或空焊原因。

规则删除后停用归档，勾选“显示已删除规则”即可恢复。核心管线只读，可在“V2规则总览”查看。规则变更历史保存在配置中，不混入人工元件结果。

项目仅自动识别，未匹配专属项目时使用基础规则。新增三组项目的71条缺件原因规则，原34条保留。三组275/286/250个盲点均完成逐点核对；第二组同值同因合并为26组，第三组补齐手工表漏列的C101。详情见[三组差异分析](docs/three-project-rule-analysis.md)。项目特例不应用于其他板卡。

“人工修改日志”只显示人工实际修改或完成原因选择后的最终五列：位号、类型、检测项目、标准值、原因。自动分类、原样保存和规则管理操作不显示。同一报告、同一检测项目、同一源元件多次修改只显示最后结果，最新在前。

运行配置位于 `%LOCALAPPDATA%\ICTCoverageBlindPointConverter\rules-v4.json`。首次迁移已有V3/V2配置，旧文件保留，自定义和归档规则保留。人工最终结果按报告指纹、检测项目和源行保存，重复读取时可恢复；旧会话按缺件兼容。

## 开发与发布

源码需要 .NET 8 SDK。运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Version 0.4.0
```

源码中的 samples 用于回归测试，运行包不依赖它。原始规则台账和历史差异在 docs 中保留；当前行为以v0.4.0说明为准。本机112项回归通过；新增三组原始报告不加入公开仓库，缺少本机外部样例清单时该项测试明确跳过。

## v0.3.1 更新

D/Q/IC与其他元件统一使用报告符号筛选，不查看程序。规则总览分别显示“当前执行”和“历史依据”，旧程序字段只保留兼容和追溯用途，不参与校验或拦截。默认运行规则版本2.1.1，原有自定义规则及其版本保留。每次仍只生成一个盲点表.xlsx。

## v0.3.2 文件占用修复

Coverage在Excel/WPS中打开时，可读取其已保存内容。导入期间使用同一份只读副本，不修改源文件；会话指纹不再反复读取原文件。若程序对文件使用完全独占锁，请保存并关闭该报告后重试。未保存的编辑内容需要先保存，再点击“读取分析”。
