## 登录

启动后显示壁纸登录页，用户名默认“陈俊杰”，每次输入约定密码后进入软件。支持显示密码、Enter提交及错误提示；不联网、不记住密码。完整英文及中文标题搭配约0.8秒入场动画，结束后停止动画。

## 使用说明与导航

左侧提供分类筛选、复制整理、待确认项、盲点设置、分类设置、规则设置、规则总览、修改记录和使用说明。菜单间距统一，待确认数量单独以橙色显示，小窗口可滚动菜单。

“使用说明”无需联网或导入报告即可阅读，包含每个菜单的用途、操作步骤、R103/R104完整示例、导出范围和常见问题；上方目录可切换章节。保留WHAPPY署名，不加入山水图片或工程师名片。

## 导入性能

主表使用轻量视口绘制，仅绘制可见行，行缓存最多64项并按16MB预算限制；异常列表按需显示，隐藏页面打开时才刷新。快速滚轮每16毫秒合并处理。筛选缓存四项展示结果，修改原因或更换规则后刷新缓存。搜索停顿180毫秒后统一执行。文件读取、规则匹配、人工记录恢复与保存均在后台执行，状态栏显示阶段。[性能说明](docs/RELEASE-v0.5.3.md)记录MG0335的1740条实表导入、连续绘制和空闲CPU检查。

## 查看报告

1. 导入或拖入`.xls/.xlsx`报告，默认全部元件类型、全部检测项目、全部状态。
2. 左侧固定切换全部、缺件、短路、错件、空焊；主表每条源记录一行，同时显示四项符号、类型、位置、标准值和原因。
3. 全部视图的Х表示任一项Х；√表示适用项均可测；∕表示提供的项目均不适用。未知符号独立待确认，四项源状态不会被改写。
4. 类型“待确认”筛选存在原因、分类或数据问题的记录。五项概览随元件范围更新，不将同一源行按四项重复计数。

左侧统计在“全部”时显示缺件统计；切换具体检测项目后显示该项整板统计。**值针率继续手动输入**，在默认收起的“输出设置”中填写。

## 复制与批量确认

- “复制整理”独立成页，位号和工具默认折叠，点击展开。只保留“复制本组位号”和“复制本组四列”，四列从Excel B列粘贴，位号为`R103.R104.`并保留单元格内换行。
- 复制只整理Х；左侧为全部时按缺件准备复制，切换具体项目可整理其Х分组。类别、标准值、原因分别分组，TVS不混入普通二极管。
- “待确认项”勾选记录、选择原因后批量确认。提交前显示数量和检测项目范围；文件数据问题不能批量绕过，可用“单条校准”检查。
- 批量操作只改原因，不改符号、位号、类型和标准值。整体校验、原子保存后才更新界面，失败不留下部分结果。
- “修改记录”只保留每个报告、检测项目、源记录的最终结果，原样保存不重复记日志。

## 导出盲点表

“**导出盲点表**”始终输出整板ICT缺件Х，**不受当前查看筛选影响**。每次只生成一个固定模板xlsx，没有核对报告、人工日志等附件。没有缺件列或没有缺件Х时不生成空文件。

未知原因写“待确定”，允许正常导出；重复位号等文件问题仍单独提示。保持模板标题、字体、列宽、边框、备注、签字和打印区域。超长分组超过Excel行高上限时，按完整位号自动续行，每行数量按实际位号计算，不缩小字体或截断内容。

“规则总览”只显示编号、阶段、优先级和当前执行，上方简写“样品训练”；项目、历史依据和具体来源不在总览显示，完整追溯仍保存在规则配置和历史文档。恢复v0.3.2式左侧品牌区和设计人员署名，图片完整缩放；其余保持v0.5布局。

## 分类设置

“分类设置”可搜索、新增、改名、删除和恢复元件分类，维护基础前缀（如R、RA、TVS）。保存后同步筛选列表并重新分类；删除保留历史，对应元件进入待确认，原始检测符号不变。分类改名同步关联规则及旧人工结果，项目专属映射继续保留。

## 规则与盲点设置

“盲点设置”可搜索、新增、改名、删除和恢复原因，保存后同步选择列表和关联规则，操作历史独立保存。

“规则设置”恢复简洁列表，不显示检测项目。常用表单只有元件类型、前缀或位号、后缀、标准值、盲点原因；高级参数默认收起。新规则适用四项，旧规则保留原范围和隐藏条件；删除可恢复，原编号和来源保留。

检测只认Coverage的Х/X/×、√、∕，黄色底纹和NP不改变检测结论。不查看测试程序，不计算10%/30%。项目特例按完整项目号自动识别，矛盾不自动训练。

规则2.3.0共326条：原105条、11条新共性规则、210条项目补充。新共性规则对既有四个已校准项目保留兼容边界，不改写旧项目已确认分类。四组新样例缺件盲点54/358/1144/1022；BC整板704条，其中包含一条PCB、√记录。0335/0336分别15/1个矛盾位号保留待确定。

## 配置与开发

运行配置位于`%LOCALAPPDATA%\ICTCoverageBlindPointConverter\rules-v6.json`，首次从V5/V4/V3/V2迁移并保留旧文件，旧版程序继续使用旧配置。会话按报告指纹、检测项目和源行定位，新会话保存在sessions-v6，仅保存最终人工修改，兼容恢复旧人工记录。

源码需要.NET 8 SDK：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Version 0.5.4
```

运行包自带.NET。样例来源和历史说明在docs中保留；四组新原文件不随公开源码分发。缺少本地外部样例时明确跳过，不将历史结果当作本次重跑。本版回归144项：143通过，旧三组原文件缺失的一项跳过；四组新样例在本机逐点验证。
